# Koers Engineering

Static Jekyll site for https://www.koers-eng.com/.

## Requirements

- Ruby with Bundler
- Node.js 22.18+ and npm 10+

## Setup

```sh
bundle install
npm install
```

## Development

```sh
npm run dev
```

The development server runs at http://localhost:3000 with BrowserSync.

## Production build

```sh
npm run build
```

The generated site is written to `dist/`.
